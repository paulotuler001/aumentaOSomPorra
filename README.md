# aumentaOSomPorra
Ferramenta para controlar músicas, dá para: Pausar, Aumentar/Diminuir Volume

# Como usar?

- Instale o arquivo <a href="@paulotuler001/aumentaOSomPorra/files/AumentaOSomPorra.exe" download>Baixar AumentaOSomPorra.exe</a>

- Ele vai criar dois arquivos de configuração

- Vai ficar aberto na bandeja do Windows

- Use os atalhos e seja feliz!
